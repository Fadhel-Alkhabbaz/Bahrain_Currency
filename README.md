# 🪙 Bahraini Currency Identifier & Calculator

An end-to-end Deep Learning & Computer Vision web application built with **Streamlit** and **Keras / TensorFlow**. The app identifies Bahraini currency denominations from uploaded images or real-time camera capture and automatically calculates the accumulated balance.

---

## ✨ Features

- 📷 **Flexible Input Methods:** Upload currency images (`.jpg`, `.jpeg`, `.png`) or take live photos using your device camera.
- 🧠 **Custom CNN Architecture:** Driven by a Convolutional Neural Network trained on Bahraini currency units.
- 📊 **Confidence Tracking:** Displays model prediction certainty along with an interactive progress score.
- 🧮 **Interactive Calculator:** Accumulates detected denominations into a running session total in BHD.
- 📜 **Transaction History Log:** Displays an itemized table of added currencies using Pandas DataFrames.
